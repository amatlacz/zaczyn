# Other interfaces and portability

Codex, Antigravity, and Kiro now have workspace skill packages and dedicated native guides in the adapter index. Use those exported packages rather than importing an individual source folder from core/skills: source folders still share repository-relative resources, while exports carry their own dependencies.

## Grok and other chat environments

The generated chat edition remains an optional explicit-reference path. Use it only when the host supports the necessary sources/instructions, and verify saving and fresh-conversation access. It is not the installation path for Codex, Antigravity, or Kiro.

Official Grok reference: [web/app FAQ](https://docs.x.ai/grok/faq).

## Moving among hosts

Transfer selected AGENTS/PROJECT context, local procedures, and needed task records. Keep a backup and mark one current version. Reconfigure and verify tools at the destination; do not transfer an “installed” or “signed in” claim without checking. Export personal or employer material only within the selected scope. There is no automatic cross-host synchronization.
