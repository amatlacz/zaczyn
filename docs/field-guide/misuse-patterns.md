# Skill misuse patterns (stub)

A rogues' gallery — you don't know what you don't know, so here's what going wrong looks like:

1. **Skill as one-shot prompt** — writing a skill for something you'll do once. That's just a message; send the message.
2. **The everything-skill** — so broad it triggers always or never. A skill should know when it's needed.
3. **Write once, never iterate** — skills are drafts; they improve only against real outputs.
4. **Skills as magic** — a skill is instructions someone must maintain, not a wish.
5. **Avoiding structure out of fear of mess** — renting a second building to keep sawdust off the showroom floor. Build a workbench room instead: that's what `scratch/` is.
