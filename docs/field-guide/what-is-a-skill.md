# What is a skill? (stub)

A skill is a written instruction set your agent consults for a specific kind of task — closer to a recipe card in the kitchen than a magic spell.

When does a task deserve one? Roughly: you've done it (or will do it) **more than twice**, the steps are **describable**, and you keep **re-explaining the same context** to your agent. The Zaczyn intake detects this (Q2: recurring) and routes you here with your task description already captured.
