# Issue-report recipe

Use for drafting an issue report from observed testing evidence. Do not use for correspondence or invent evidence to fill a field.

Capture a concise summary, relevant environment, steps actually taken, expected behavior, actual behavior, and available evidence. Label unknowns and distinguish observations from suspected causes. Check that another tester could follow the steps. Prepare the draft at the agreed location; submission requires the user's requested workflow and actual tracker access.

Source: workspace customization example for Zaczyn 0.4.0. Selected explicitly through AGENTS.md; not installed as a native skill. Revise or remove that pointer to change when this recipe applies.
